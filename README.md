## Инструкция по запуску

### Подготовка конфигурации (`input.txt`)
Файл должен содержать параметры в следующем порядке:
1.  `Итерации` и `коэффициент демпфирования` (alpha).
2.  `Флаги параметров` (7 целых чисел: 1 — оптимизировать, 0 — зафиксировать).
3.  `Начальные данные` (18 чисел: параметры для 3 звезд).
4.  `Начальная масса` черной дыры.
5.  `Проценты шума` (7 чисел: уровень искажения для каждого из 7 типов параметров).

log.txt — содержит детальный ход процесса каждой итерации, значения ошибок и матрицу системы.

result.txt — содержит итоговые уточненные параметры звезд и массы в удобном для чтения виде.
